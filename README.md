# Семь подземных королей

Школьный проект по литературному чтению для 4 класса.
Автор: **Никита Савоськин**.

Презентация по сказочной повести Александра Волкова «Семь подземных королей».

## Файлы

- `index.html` — презентация для браузера с плавными анимациями и заметками для рассказа.
- `Семь подземных королей.pptx` — файл PowerPoint для школы.
- `Семь подземных королей.pdf` — версия для просмотра без PowerPoint.

## Как открыть

### PowerPoint
Скачайте файл `Семь подземных королей.pptx` и откройте в PowerPoint. На каждом слайде есть заметки для рассказа.

### Браузер
Откройте `index.html` или онлайн-версию на GitHub Pages.

Управление:
- `←` `→` или пробел — переключение слайдов;
- `N` — заметки для рассказа;
- `F` — полноэкранный режим;
- кнопка `PDF` — сохранение в PDF.

### PDF
Файл `Семь подземных королей.pdf` открывается на любом устройстве без установки PowerPoint.
